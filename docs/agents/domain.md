# Domain documentation

This repository uses one domain context.

Before exploring or changing behavior:
- Read GLOSSARY.md and use its canonical terminology.
- Read relevant decisions in docs/adr/.
- Read docs/design.md for the approved initial milestone.
- Consult docs/post-milestone-design.md for longer-term proposals;
  these are not initial-milestone requirements.

Surface conflicts with existing ADRs explicitly.
Keep glossary definitions separate from implementation decisions.
